# 双语紧凑型个人简历网站

这是一个无需后台、可直接发布的静态简历网站。设计采用固定个人信息栏与四个内容标签页，桌面端主要信息尽量保持在一个视口内，不再依赖长页面滚动。

## 页面结构

- **关于**：个人介绍、所在地、方向、语言和核心数字。
- **经历**：两段工作经历、教育背景与当前关注方向。
- **项目**：三个代表项目，通过弹窗查看详情。
- **技能与证书**：技能标签、能力概览、证书和 PDF 简历入口。

栏目通过无刷新标签切换，网址中的 `#about`、`#experience`、`#projects` 和 `#skills` 可以直接打开对应内容。

## 交互与适配

- 全页面中文 / English 切换，并记住访客的选择。
- 深浅色模式、卡片光效、轻微 3D 倾斜和视觉视差。
- 工作经历展开、技能标签点选、项目详情弹窗。
- 桌面端隐藏页面级滚动条；手机端只在当前标签内容超出时使用短距离内部滚动。
- 支持键盘方向键切换栏目，并尊重系统“减少动态效果”设置。

## 个性化

1. 在 `index.html` 中替换姓名、邮箱、链接、年份和数字。
2. 在 `script.js` 的 `translations.zh` 与 `translations.en` 中同步替换中英文内容。
3. 将头像区域替换为你的照片，或继续使用姓名缩写图形。
4. 将 PDF 简历命名为 `resume.pdf` 放在根目录。
5. 在 `projectDetails` 中编辑三个项目弹窗的中英文详情。

## 发布为公开网站

### GitHub Pages

1. 在 GitHub 新建公开仓库；根域网站的仓库名应为 `用户名.github.io`。
2. 上传这里的全部文件并提交。
3. 打开 **Settings → Pages**，选择 **Deploy from a branch**、`main` 和 `/root`。
4. 保存并等待几分钟，GitHub 会显示公开网址。

## 文件说明

- `index.html`：页面结构与个人信息
- `styles.css`：单屏布局、卡片样式、互动和移动端适配
- `script.js`：标签切换、中英切换、深浅色和弹窗交互
- `favicon.svg`：浏览器标签页图标
- `resume.pdf`：需要自行加入的 PDF 简历
